# PMP practice exams

Self-contained PMP mock exams and tooling to sync the Andrew Ramdayal 200-question set from the source PDF.

## Open an exam

| File | Description |
|------|-------------|
| [pmp-mock-andrew.html](pmp-mock-andrew.html) | 200 Ultra Hard Questions (Andrew Ramdayal) |
| [pmp-mock-david.html](pmp-mock-david.html) | 150 PMBOK 7 scenario questions (David McLachlan) |
| [pmp-mock-mindset.html](pmp-mock-mindset.html) | 50 mindset principles practice |

Open any HTML file in a browser (double-click or serve locally).

## Andrew exam — PDF sync workflow

Requires Python 3 and `PyPDF2` (`pip install PyPDF2`).

From this folder (`pmp/`):

```bash
# 1. Parse AR_200.pdf → scripts/ar200_from_pdf.json
python scripts/parse_ar200_pdf.py

# 2. Compare parsed answers with the HTML (should report 0 mismatches)
python scripts/compare_and_build.py

# 3. Merge PDF text/options/answers into pmp-mock-andrew.html (keeps explanations & video links)
python scripts/patch_html_questions.py
```

### Files

- `AR_200.pdf` — source question bank for the Andrew mock
- `scripts/ar200_from_pdf.json` — parsed output (regenerated by `parse_ar200_pdf.py`)
- `scripts/parse_ar200_pdf.py` — PDF parser
- `scripts/patch_html_questions.py` — updates `pmp-mock-andrew.html` from parsed JSON
- `scripts/compare_and_build.py` — diff HTML answers vs PDF
- `scripts/debug_parse.py`, `scripts/show_q77.py` — ad-hoc PDF debugging helpers
